# Novedades de ExplorerFrame

## v1.2 — Actualización importante

### Nuevas características

- **API REST mejorada**: Endpoints optimizados para mejor rendimiento
- **Notificaciones en tiempo real**: Recibe alertas del servidor cada 10 segundos
- **Diseño responsive**: Interfaz optimizada para dispositivos móviles
- **Service Worker actualizado**: Funciona offline con mejor caché

### Mejoras de seguridad

- Tokens JWT con expiración de 30 días
- Contraseñas hasheadas con bcrypt
- Tokens de descarga de un solo uso
- Middleware de seguridad mejorado

### Correcciones

- Corregido error 404 en noticias
- Optimizado tiempo de carga en móviles
- Mejor manejo de errores de red
